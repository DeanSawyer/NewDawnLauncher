# Free Realms: New Dawn Launcher

**The desktop launcher for Free Realms: New Dawn.**

*Preserving the past. Rebuilding the experience. Creating a new dawn.*

## Overview

**New Dawn Launcher** is an independently maintained, open-source launcher for the **Free Realms: New Dawn** preservation and emulator development project. It is derived from the [Open Source Free Realms Launcher](https://github.com/Open-Source-Free-Realms/Launcher) and will be developed as a separate application for configuring and launching compatible Free Realms environments.

New Dawn is an unofficial community project and is not an official release of Open Source Free Realms (OSFR).

## Development objectives

- Provide a straightforward Windows desktop experience for launching compatible game clients.
- Support configurable server connections and clear launch diagnostics.
- Improve installation, file verification, and update workflows as development permits.
- Create a distinct New Dawn interface, branding, and user experience.
- Keep source code, build instructions, and releases understandable and maintainable.

**These are goals, not a statement that every feature is currently available.**

## Current status

**Early independent development.** This fork initially carries the upstream launcher implementation. Branding, workflows, dependencies, and functionality may change. No production-readiness or compatibility guarantee is implied.

## Building from source

The upstream project documents a Windows `build.bat` workflow. Build requirements and commands will be verified and documented here as we inspect and test the fork.

Do not assume an installer or release exists for New Dawn until it has been built and published in this repository.
